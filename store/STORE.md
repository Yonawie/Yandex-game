# Витрина · Эхо

**Название:** Эхо  
**Жанр:** слова / аркада / головоломка  
**Кратко:** Ломай стену букв своим словом. Осыпь даёт эхо-трей для второго удара. Не дай стене дорасти до потолка.

**Как играть:** Собери слово из трея → **УДАР**. Если слово есть в словаре и задевает буквы стены — кубы ломаются, осколки дают эхо-ход. Не дай стене коснуться потолка.

**Теги:** слова, аркада, реакция, endless, буквы, комбо  
**Ориентация:** портрет · **Возраст:** 0+  
**Категории:** головоломки / слова
