# Витрина · Эхо

**Название:** Эхо  
**Жанр:** слова / аркада / головоломка  
**Кратко:** Ломай стену букв своим словом. Осыпь даёт эхо-трей для второго удара. Не дай стене дорасти до потолка.

**Как играть:** Собери слово из трея → **УДАР**. Если слово есть в словаре и задевает буквы стены — кубы ломаются, осколки дают эхо-ход. Не дай стене коснуться потолка.

**Теги:** слова, аркада, реакция, endless, буквы, комбо  
**Ориентация:** портрет · **Возраст:** 0+  
**Категории:** головоломки / слова

## Материалы для кабинета (готовые файлы)

| Поле | Файл | Размер |
|---|---|---|
| Иконка | `icon-512.png` | 512×512 PNG |
| Иконка (запасная, из favicon) | `icon-512-from-favicon.png` | 512×512 PNG |
| Обложка | `cover-800x470.jpg` | 800×470 JPEG |
| Обложка (широкая) | `cover-1560x520.jpg` | 1560×520 JPEG |
| Скрин меню | `shot-menu-1080x1920.jpg` | 1080×1920 · 9:16 |
| Скрин игры | `shot-play-1080x1920.jpg` | 1080×1920 · 9:16 |

Минимум для мобильных: **2** портретных скрина. Загружай `shot-menu` + `shot-play` (+ `shot-strike` опционально).

> Скрины — рекламные макеты в стиле геймплея. Перед модерацией желательно заменить на живые кадры из билда (`npm run play` / стенд).

## Чеклист загрузки

1. `npm run pack` → `release/echo-yandex.zip`
2. Иконка + обе обложки + ≥2 скрина
3. Leaderboard **`score`**
4. Ориентация: портрет · платформы: мобильные (+ десктоп по желанию)
