# Эхо — полное описание интерфейса

Документ: все экраны, иконки, кнопки, индикаторы и подписи.

---

## 0. Общая схема экранов

```
Меню ──► Игра ──► Результат ──► Меню
  │         ▲          │
  └──────► Стили ◄─────┘
```

Фазы: `menu` · `shop` · `playing` · `result`

Валюта: **◆ осколки** (покупают стили).  
За забег: `осколки += max(5, score / 8)`.  
Новым игрокам: **250 ◆**.

---

## 1. Экран «Меню»

### Визуал
- Фоновый градиент и паттерн **активного стиля**
- В центре: демо-кубики `Э Х О С Л О В` (часть «осыпается»)
- Свечение-аура вокруг логотипа

### Тексты и иконки
| Элемент | Что показывает |
|---|---|
| **Эхо** | Название игры (крупный бренд) |
| Подзаголовок | `Ломай стену словом · собирай стили` |
| **◆ N осколков** | Баланс валюты |
| `рекорд N` | Лучший счёт |

### Кнопки
| Кнопка | Действие |
|---|---|
| **Играть · Норма** | Старт обычной сложности (primary) |
| **Лёгкий** | Старт лёгкого режима |
| **Сложный** | Старт сложного режима |
| **∞ Бесконечность** | Режим ∞ с бронёй/зеркалами (primary) |
| **✦ Стили** | Открыть магазин стилей |

## 2. Экран «Стили» (магазин)

### Шапка
| Элемент | Смысл |
|---|---|
| Заголовок **Стили** | Название экрана |
| **◆ N** | Текущие осколки |

### Карточка стиля (повтор для каждого)
| Элемент | Смысл |
|---|---|
| 3 цветных квадрата | Превью: кубик · акцент · редкий |
| Название | Имя стиля |
| Подпись | Короткий слоган темы |
| Кнопка справа | Покупка / экипировка |

### Кнопка на карточке (состояния)
| Текст | Когда | Действие |
|---|---|---|
| **◆ цена** | Не куплен | Купить, если хватает осколков, и сразу надеть |
| **Надеть** | Куплен, не активен | Экипировать |
| **Надет** | Уже активен | Ничего (уже выбран) |

## 3. Экран «Игра»

### 3.1 Верхний HUD

**Слева — панель очков**
| Элемент | Смысл |
|---|---|
| Крупное число | Текущий счёт забега |
| Подпись **ОЧКИ** | Метка панели |

**Справа — панель режима**
| Элемент | Смысл |
|---|---|
| `Лёгкий` / `Норма` / `Сложный` / `∞ ×N` | Режим (в ∞ — множитель) |
| `цепь ×N` | Показывается при серии эхо-ударов |
| иначе **◆ N** | Баланс осколков |

**Центр — камни редкости**
| Иконка | Смысл |
|---|---|
| **Ф** · **Ц** · **Щ** | Счётчик редких букв в серии |
| Подпись `×1.35` / `×1.6` / `×2.2` | Множитель комбо редкости |

Камни подсвечиваются, когда серия активна.

---

### 3.2 Поле стены

| Элемент | Смысл |
|---|---|
| Рамка-панель | Контейнер стены |
| Пунктир сверху | Линия **потолка** (смерть) |
| Текст `потолок` | Метка линии |
| Текст **⚠ ПОТОЛОК** | Рядом со смертью (столбы почти у линии) |
| Кубики с буквами | Кирпичи стены (кириллица) |
| Подсветка кубиков | Цели, которые выбьет **текущее** собранное слово |
| Метка **N+** на кубике | Броня: нужно слово длины ≥ N (сложный / ∞) |
| Метка **◐** на кубике | Зеркало: при сбитии добавляет кубик в низкий столбец |
| Рамка вокруг редких Ф/Ц/Щ | Особые буквы на стене |
| Круговая волна | Эффект эхо-взрыва |
| Гигантский штамп слова | На долю секунды имя удара (`ФАКТ` и т.п.) |
| Летящие буквы/искры | Осколки после удара |

---

### 3.3 Полоса давления (под стеной)

| Режим | Подпись на полосе | Что тает |
|---|---|---|
| Обычный | **РОСТ СТЕНЫ** | Время до принудительного роста |
| Эхо-окно | **ЭХО — УСПЕЙ ВТОРОЙ УДАР** | Оставшееся время эхо-трея |

---

### 3.4 Панель слова / трея

**Панель над буквами**
| Состояние | Текст |
|---|---|
| Слово собрано | Само слово + `выбьет N ▦` или `нет букв стены` |
| Слова нет, есть хинт | `можно: СЛОВО` |
| Иначе | `собери слово` / `эхо-трей` |

**Трей букв**
| Элемент | Смысл |
|---|---|
| Квадрат с буквой | Буква в руке; тап добавляет в слово |
| Номер 1…N в углу | Порядок букв в собираемом слове |
| Пустой слот | Буква уже потрачена |
| Подсветка / подпрыгивание | Буква выбрана |
| Цвет редких | Ф/Ц/Щ выделены |

Повторный тап по **последней** выбранной букве снимает её.

---

### 3.5 Кнопки управления (низ)

| Кнопка | ID | Действие |
|---|---|---|
| **☰** | `to-menu` | Выход в меню (стоп GameplayAPI) |
| **↩** | `undo` | Отменить последнюю букву слова |
| **!** | `hint` | Автоматом выбрать подсказанное слово |
| **УДАР** | `submit` | Сдать слово и атаковать стену (главная) |
| **Сброс** | `reshuffle` | Новый трей (в Сложном — стена чуть растёт) |

### Клавиатура (десктоп)
| Клавиша | Действие |
|---|---|
| **Enter** | Удар |
| **Backspace** / **Esc** | Отмена последней буквы |

---

### 3.6 Всплывающие сообщения (тост)
Примеры:
- `Собери слово и жми УДАР · подсказка внизу`
- `«СЛОВО» нет в словаре · попробуй «ХИНТ»`
- `Нужна хотя бы одна буква со стены · жми «!»`
- `Эхо Ns · цепь ×N · бей ещё!`
- `Стена растёт…`
- `Новый трей · можно «…»`
- `Во время эха сброс недоступен`
- `Не хватает осколков`
- `Куплено · …` / `Стиль «…» экипирован`

Плавающий счёт: `+N` или `ЭХО +N`, в ∞ при жирном эхе — `∞ ×N.NN`.

## 4. Экран «Результат» (Потолок!)

Появляется, когда любой столбец стены достигает потолка.

| Элемент | Смысл |
|---|---|
| Заголовок **Потолок!** | Поражение |
| Крупный счёт | Итог забега |
| `лучшее · СЛОВО · сбито N` | Лучшее слово и число сбитых кубиков |
| `+N осколков · всего ◆ M` | Награда забега и новый баланс |

### Кнопки
| Кнопка | Действие |
|---|---|
| **Ещё раз** | Рестарт той же сложности |
| **Реклама · срезать верх** | Rewarded: срезать верхушки столбов и продолжить (1× за забег; скрывается после использования) |
| **✦ Стили** | Открыть магазин |
| **В меню** | Выход в главное меню |

---

## 5. Иконка приложения / favicon

Квадрат с тёмным фоном, три столбца-кубика разной высоты (янтарь / коралл), блик и дуга эха — силуэт «растущая стена + удар».

Тема-цвет браузера: `#0B1C24`.

---

## 6. Что меняет стиль (все экраны)

У активного стиля перекрашиваются:
- фон и декоративный паттерн
- кубики стены и трея
- панели HUD / магазина / результата
- кнопка **УДАР** и акценты
- частицы осыпи и штамп слова
- цвета редкости Ф/Ц/Щ и опасности потолка
