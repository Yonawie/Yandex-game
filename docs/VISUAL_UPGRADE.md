# Эхо — масштабный визуальный апгрейд (без Unity)

## Цель

Оставить HTML5/Yandex-стек, но дать «AAA mobile» ощущение:
материалы, свет, кинематографичный удар, живая сцена.

## Архитектура

```
┌─────────────────────────────────────┐
│  #world  — PixiJS (WebGL)           │
│  · parallax фон                     │
│  · кубики-спрайты из MaterialAtlas  │
│  · debris / shockwave / stamp       │
│  · color grade filter               │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│  #game   — Canvas 2D HUD            │
│  · очки / камни / трей / УДАР       │
│  · меню / магазин / результат       │
└─────────────────────────────────────┘
              ▲
              │ GSAP timelines
         VfxDirector
              │
           Game.ts (логика)
```

## Модули

| Модуль | Роль |
|--------|------|
| `visual/MaterialFactory` | Runtime-атласы кубиков по стилю (bevel, vein, frost…) |
| `visual/WorldView` | Pixi-сцена: фон, стена, дыхание, параллакс |
| `visual/VfxDirector` | Таймлайн удара: crack → flash → shatter → dust → stamp |
| `audio/sfx` | Материало-зависимые бусты + haptic |

## Последовательность удара (фирменный эффект)

1. 0–80 ms — трещины по кубикам  
2. 40–180 ms — ударная волна + screen flash  
3. 80–400 ms — осколки материала стиля  
4. 120–700 ms — пыль / свечение  
5. 0–900 ms — гигантский штамп слова  

## Результат для игрока

- Стена выглядит как единая тяжёлая конструкция  
- Каждый стиль ломается иначе (звук + осколки + материал)  
- Удар ощущается физически (shake + haptic + cinematic timing)
