# Visual Bible — Найди что-то

## Направление

Тёмная премиум-оболочка (deep navy + gold) вокруг плотных «живых» Wimmelbild-карт.
Бренд «Найди что-то» — hero-level на первом экране.

## Типографика

- Display: **Fraunces**
- UI: **Manrope**

## Juice (минимум)

1. Hit-stop 40–70 ms при находке  
2. Screen shake при ошибке  
3. Shockwave-кольцо  
4. Material shred particles  
5. Fullscreen stamp на победе  
6. Button depress на CTA  
7. Haptic vibrate 12–32 ms  
8. SFX: transient + body + tail (WebAudio)
