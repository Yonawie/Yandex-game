# ТЗ: «Сотослов» / Hiveword

> Версия 1.0 · HTML5 · Яндекс Игры · TypeScript + Vite + Canvas + Yandex Games SDK  
> Жанр: словесная стратегия размещения · соты · survival / endless

---

## 0. Вердикт: какую игру делаем и почему она залипает

### 0.1 Ниша

На Яндекс Играх полно классических «собери слово» (Wordament-likes) и отдельных плиточных стратегий. Редко встречается гибрид:

**размещение букв как в кирпичиках + словарь + выживание на сужающемся поле.**

Игрок постоянно решает напряжение «хочу длинное слово ради бонуса» vs «если положу слишком много — задохнусь».

### 0.2 Формула залипания

1. **3 секунды понятности** — бери буквы → клади цепочкой по сотам → отправь слово.  
2. **Дофамин каждые 8–20 с** — валидное слово, очки, искры, комбо за Ц/Щ/Ф.  
3. **Отложенный джекпот** — слова **длиннее 5** открывают ячейки-множители; без них поле замуровывается.  
4. **Катарсис очистки** — множитель «лопает» кирпичи как мыльные пузыри (звук + волны + иридесцентные брызги).  
5. **«Ещё партию»** — смерть от полного поля; в Endless очистка даёт ×очки, но поле **сжимается**.  
6. **Скриншотность** — стекловидные соты, иридесцентный мыльный блик, тёплый янтарь кирпичей.

### 0.3 Концепция

| | |
|---|---|
| **Название RU** | Сотослов |
| **Название EN** | Hiveword |
| **Slug** | `sotoslov` / `hiveword` |
| **Жанр** | Word placement strategy / survival puzzle |
| **Платформа** | Яндекс Игры (HTML5), портрет |
| **Возраст** | 0+ · без насилия |
| **Язык слов** | русский (основной), словарь вшит в клиент |

**Логлайн:** На сотах растут буквы-пузыри. Составь слово — и они застынут кирпичами. Длинные слова открывают множители, которые лопают кладку. Не дай сотам замуровать тебя — или войди в режим «Бесконечность», где каждый взрыв делает поле меньше, а очки — жирнее.

**USP:**
- Буквы не исчезают после слова — превращаются в **кирпичи** (placement pressure).  
- Множители **заперты**, пока не составишь слово из 6+ букв.  
- Очистка поля = **лопнувший пузырь**, не «исчезновение тайла».  
- Endless: clear → score mult ↑, playable radius ↓.

## 2. Core loop

```
Трей букв → размещение смежных клеток → отправка слова
  ├─ неверно → лёгкий shake, буквы остаются в трее / снимаются с поля
  └─ верно → буквы → КИРПИЧИ → очки → (если len>5) открытие множителей
       → если путь слова задел активный множитель → ПУЗЫРЬ-ВЗРЫВ (очистка зоны)
       → новый набор букв в трей
Поле заполнено / нет хода → Game Over
```

## 3. Поле и размещение

### 3.1 Гексагональная сетка (axial coords)

| Режим | Стартовый радиус R | Ячеек | Примечание |
|---|---|---|---|
| Лёгкий | 3 | 37 | больше воздуха |
| Норма | 3 | 37 | базовый баланс |
| Сложный | 2 | 19 | тесно с первой минуты |
| Бесконечность | 4 | 61 | сужается после clear |

Пустые ячейки — стекло-пузыри. Кирпичи — матовые янтарь-соты с буквой-отпечатком.

### 3.2 Трей букв

- Размер трея: **7** букв (как в классике, знакомо).  
- Частоты приближены к русскому: О, Е, А, И… частые; **Ц, Щ, Ф, Ъ, Ь** редкие.  
- После принятого слова: израсходованные буквы заменяются новыми; «мусор» можно **сбросить** 1 раз за ход за −15 % текущего комбо (или бесплатный сброс через rewarded).

### 3.3 Правила слова

1. Буквы из трея кладутся на **пустые** смежные (edge-neighbor) ячейки — образуется полиомино-путь.  
2. Порядок чтения = порядок размещения (или путь графа без разрывов).  
3. Длина ≥ 2.  
4. Слово ∈ словаре (нормализация: ё→е, верхний регистр).  
5. Одноразовая ячейка за слово; нельзя класть поверх кирпича.

## 4. Очки, кирпичи, множители

### 4.1 Базовая формула

```
base = Σ letterValue(c) * lengthCoef(len)
score += base * comboMult * cellMultProduct * infinityMult
```

| Длина | lengthCoef |
|---|---|
| 2–3 | 1.0 |
| 4–5 | 1.4 |
| 6–7 | 2.0 + **unlock cascade** |
| 8+ | 3.0 + большой unlock |

**Letter values (фрагмент):** гласные 1; частые согласные 2–3; **Ф=8, Ц=9, Щ=10**; Ъ/Ь = 4 (трудны в слове).

### 4.2 Кирпичи

После валидного слова все занятые этим словом ячейки становятся `BRICK`.  
Они **блокируют** размещение. Визуально: пузырь «застывает» (поверхностное натяжение → матовый янтарь) за ~280 мс.

### 4.3 Бонусные ячейки-множители (главный крючок)

- На старте под случайными пустыми клетками спрятаны слоты `×2 / ×3 / ★POP`.  
- Они **невидимы и неактивны**, пока игрок не составит слово длины **> 5**.  
- При первом таком слове: 2–4 ближайших слота **открываются** с ripple-анимацией.  
- Пока множитель активен на клетке:  
  - клетка может быть пустой (× ждёт размещения) или уже кирпич со «штампом» множителя;  
  - если путь нового слова проходит через клетку с активным множителем → множитель срабатывает на этот ход.

**Эффект срабатывания:**
- `×2` / `×3` — умножают очки слова;  
- `★POP` — запускает **Пузырь-очистку** радиуса 1 (норма) / 2 (если комбо ≥ 3).

Открытые множители после срабатывания гаснут и могут перегенерироваться глубже в «Бесконечности».

## 5. Комбо редких букв (Ц, Щ, Ф)

| Событие | Эффект |
|---|---|
| В слове есть Ф / Ц / Щ | `rareStreak += 1` за каждую редкую |
| Слово без редких | `rareStreak = 0` |
| rareStreak 1 | комбо ×1.25 + «искра» |
| rareStreak 2 | ×1.6 + подсветка трея |
| rareStreak ≥ 3 | ×2.2 + POP-радиус +1 на следующий ★POP |

UI: полоска «Редкость» с глифами **Ф · Ц · Щ**. Срыв комбо — короткая «сдувка» пузыря.

Мотивация: игрок копит редкие в трее и **намеренно** вставляет их в длинные слова, рискуя занять лишние клетки.

## 6. Уровни сложности

| | Лёгкий | Норма | Сложный |
|---|---|---|---|
| Радиус | 3 | 3 | 2 |
| Словарь (мин. частотность) | широкий | средний | строгий (меньше редких слов) |
| Шанс ★POP среди слотов | 35 % | 25 % | 15 % |
| Старт открытых множителей | 1 уже виден | 0 | 0 |
| Штраф сброса трея | мягкий | норм | жёсткий (−комбо полностью) |
| Целевой счёт «звезды» | 800 / 1500 / 2500 | 1200 / 2500 / 4000 | 600 / 1200 / 2000 |

Режим выбирается в меню до старта рана.

## 7. Режим «Бесконечность»

Отдельная кнопка меню. Правила:

1. Старт R = 4 (61 клетка).  
2. Кирпичи и слова — как в Норме.  
3. **Очистка поля** = момент, когда после ★POP (или цепочки POP) доля кирпичей падает ниже порога **≤ 15 %** занятых **или** один POP снёс ≥ 8 кирпичей за раз.  
4. При зачтении очистки:  
   - `infinityMult *= 1.25` (кап ×5);  
   - playable radius **R −= 1** (минимум R = 2);  
   - клетки за новым радиусом становятся **обсидиановой кромкой** (недоступны); кирпичи на кромке уничтожаются с отдельным «схлопыванием»;  
   - полный **bubble rupture** VFX на весь экран.  
5. Победа не предусмотрена — только рекорд по очкам и «глубине сжатия» (сколько раз сузились).  
6. Game Over: нет пустых клеток внутри текущего R (или нет валидного хода из трея после авто-проверки + отказ от сброса).

**Психологический крючок:** каждый clear празднуется, но поле становится теснее — игрок сам выбирает, когда «пожать» джекпот.

## 8. Арт-дирекшн: «лопнувший пузырь»

### 8.1 Палитра (не фиолетовый AI-дефолт, не cream-terracotta)

```
--void:        #0B1C24
--depth:       #123A44
--glass:       #7FD4E8
--glass-hi:    #D6F7FF
--iridescent:  #B8F0C8 → #7ED8E8 → #F7E4A2 (градиент плёнки)
--brick:       #E8A85C
--brick-deep:  #C pen75  #C4753A
--rare:        #FF6B8A
--pop:         #FFF6D6
--ink:         #F2FBFD
```

Фон: вертикальный градиент глубины воды + медленный шум каустик (procedural).  
Соты: полупрозрачный stroke с specular-бликом в верхнем ребре.

### 8.2 Типографика

- Display / бренд: **Manrope** 800 (геометрия сот ↔ гротеск)  
- Буквы на поле: **Unbounded** 600  
- UI: Manrope 500–700  

Бренд **«Сотослов»** — hero-level на сплэше: крупнее любого подзаголовка.

### 8.3 Motion (обязательные ≥ 3)

1. **Застывание** — scale 1.08→1 + tint glass→brick при превращении в кирпич.  
2. **Unlock ripple** — кольцо по гексам при открытии множителя (слова 6+).  
3. **Bubble rupture** — частицы-дуги, shockwave, лёгкий chromatic split на 120 мс при POP / clear.  
4. Комбо-pulse полоски редкости.  
5. Меню: медленное «дыхание» блика на логотипе.

### 8.4 Звук

Procedural WebAudio:  
- place soft blip;  
- valid word — мажорный chord up;  
- invalid — soft muted thud;  
- POP — noise burst + sine drop (ощущение лопнувшей плёнки);  
- infinity shrink — низкий whoosh.
