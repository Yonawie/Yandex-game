# ТЗ: «ЭХО» / Echo

> Версия 2.0 · HTML5 · Яндекс Игры · TypeScript + Vite + Canvas

## Логлайн

Ломай стену чужих букв своим словом. Осыпь на миг становится оружием — успей эхо-удар, пока стена снова не поползла вверх.

## Core loop

```
Трей → слово → удар по стене → осыпь
  → эхо-окно (второй удар из упавших букв)
  → рост стены / таймер давления
Потолок достигнут → Game Over
```

## Правила удара

1. Слово ∈ словаре, длина ≥ 2.  
2. Хотя бы одна буква слова должна выбить кубик стены (с учётом брони).  
3. **ЭХО**, если: есть Ф/Ц/Щ **или** сбитые кубики образуют кластер **или** ≥2 попаданий → соседние кубики тоже падают.  
4. Упавшие буквы → временный трей (`echoWindow` сек). Цепочка ударов усиливает множитель `chain`.

## Давление

- Таймер роста стены + рост после завершённой атак-цепочки.  
- Сброс трея тоже подращивает стену.  
- Столбик высоты `maxH` = смерть.

## Сложность / ∞

| | Лёгкий | Норма | Сложный | ∞ |
|---|---|---|---|---|
| Колонны | 6 | 7 | 7 | 8 |
| Рост | медленнее | база | быстрее | +броня/зеркала |
| Броня | нет | редко | да | часто |
| Зеркало | нет | нет | да | да |

**Броня N+** — сбить можно только словом длины ≥ N.  
**Зеркало** — при ударе добавляет кубик в короткий столбец.  
**∞**: сильное эхо (много сбитых) растит глобальный множитель очков.

## Трей

`dealPlayableTray(prefer=wallTopLetters)` — seed-слово пересекается со стеной, плюс буквы с верхушек столбов. Атака всегда потенциально возможна.

## Арт

Тёмно-бордовый void, янтарные кирпичи, коралловое ЭХО, линия-потолок. Motion: shake, shockwave, falling glyphs.
