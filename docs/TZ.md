# ТЗ: «Плёнка» / Filmword

> Версия 1.1 · HTML5 · Яндекс Игры · TypeScript + Vite + Canvas  
> Эволюция: соты отказаны → мягкая ортогональная «мыльная сетка»

---

## 0. Почему не соты

Гекс-соты читаются как «ещё один hex-puzzle», плохо тапаются большим пальцем (углы), и визуально спорили с метафорой лопнувшего пузыря.  
Новое поле — **мягкие скруглённые плитки-плёнки** в прямоугольной сетке: соседство ↑↓←→, блики мыльной плёнки, кирпичи — застывший янтарь.

### Альтернативы, которые рассматривались (можно вернуть во v2)

| Идея | Суть | Почему не v1.1 |
|---|---|---|
| Речная галька | нерегулярные «камни», связь по расстоянию | сложный hit-test и баланс |
| Линия прибоя | горизонтальные волны-ряды дрейфуют | сильнее action, слабее стратегия |
| Этажи-скважины | колонки с гравитацией как тетрис | другая жанровая петля |
| Орбиты | кольца вокруг центра | красиво, но тесно на телефоне |
| **Мыльная плёнка (выбрано)** | soft-grid + ортогональ | понятно, уникальный look, быстрый прототип |

## 2. Core loop

```
Трей (гарантированно содержит слово 3–5) 
  → кладка по соседним клеткам → Готово
  → кирпичи + очки
  → (len>5) unlock множителей
  → путь через ★ = bubble POP
Поле заполнено → Game Over
∞: сильный POP → ×очки + margin++ (рамка сжимается)
```

---

## 3. Поле

| Режим | Сетка | Примечание |
|---|---|---|
| Лёгкий | 7×8 | больше воздуха |
| Норма | 6×7 | база |
| Сложный | 5×6 | тесно |
| Бесконечность | 8×9 → margin растёт | min ~4×5 |

Соседство только ортогональное. Клетки за `margin` — «оторванная плёнка», недоступны.

---

## 4. Словарь и трей (фикс «нет слов»)

- Словарь ~1700 нормализованных RU-слов (ё→е).  
- **dealPlayableTray()**: берёт seed-слово длины 3–5, кладёт его буквы в трей, досыпает weighted random до 7, перемешивает.  
- Сброс и continue тоже через playable deal.  
- Игрок всегда *может* собрать хотя бы seed (и обычно ещё несколько коротких).

---

## 5. Очки / кирпичи / множители / комбо ФЦЩ / ∞

Без изменений по замыслу v1.0 (см. историю), кроме геометрии POP (манхэттенский радиус вместо гекса).

Формула:
`score += Σletter * lengthCoef * rareCombo * cellMult * infinityMult`

---

## 6. Арт

Палитра воды + иридесценция, soft rounded tiles, застывание → янтарь, rupture при POP.  
Типографика: Manrope + Unbounded. Бренд **«Плёнка»** — hero на меню.

---

## 7. Store copy

> Клади буквы на мыльную плёнку. Каждое слово застывает кирпичом. Собери длиннее пяти — открой множители, которые лопают поле пузырём. В «Бесконечности» каждый взрыв даёт ×очки и сжимает плёнку.
