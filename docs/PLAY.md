# Как проверять игры

Одна команда для любой новой HTML5-игры в этом шаблоне:

```bash
npm run play
```

В терминале появится ссылка вида:

```text
https://….trycloudflare.com
```

Открой её на телефоне или в браузере. Остановка: `Ctrl+C`.

## Зачем так
`localhost` с cloud-агента / телефона часто не открывается (−102).  
`npm run play` поднимает Vite и публичный туннель — ссылка работает везде.

## Другие команды
| Команда | Когда |
|---|---|
| `npm run play` | Проверка с телефона / ссылка коллеге |
| `npm run dev` | Локальная разработка в Cursor Desktop (Ports → 5173) |
| `npm run pack` | zip для Консоли Яндекс Игр |

## Шаблон на следующие игры
Скопируй репозиторий / эту структуру, меняй `src/game` и `src/content`.  
Команда `npm run play` остаётся той же.
