# Как играть в «Плёнку»

```bash
npm install
npm run play
```

## Управление

1. Тап по букве в трее  
2. Тап по соседним клеткам плёнки (вверх/вниз/влево/вправо)  
3. **Готово** — сдать слово  
4. **↩** — отменить клетку · **Сброс** — новый трей (в нём снова спрятано слово)

Слова из **6+** букв открывают множители. ★ лопает кирпичи. Заполнил поле — конец.

В **Бесконечности** мощная очистка даёт множитель очков и сжимает доступную область с краёв.
