# Как играть в «Сотослов»

## Быстрый старт

```bash
npm install
npm run play
```

В терминале появится ссылка — открой на телефоне или в браузере.

Локально без туннеля:

```bash
npm run dev
```

## Управление

| Действие | Как |
|---|---|
| Взять букву | Тап по букве в трее |
| Положить на соту | Тап по пустой смежной ячейке (первая — любая пустая) |
| Отменить последнюю | Кнопка «↩» или тап по уже выбранной в пути |
| Сдать слово | «Готово» |
| Сбросить трей | «Сброс» (штрафует комбо) |
| Режим | Меню → Норма / Сложный / Бесконечность |

## Цель

Составляй русские слова. Буквы превращаются в **кирпичи** и занимают поле.  
Слова **из 6+ букв** открывают множители. Множитель ★ лопает кирпичи пузырём.  
Заполнил всё — конец. В **Бесконечности** сильная очистка даёт ×очки и сужает поле.

## Сборка для Яндекс Игр

```bash
npm run pack
```
