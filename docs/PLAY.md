# Как играть в «ЭХО»

1. Тапай буквы трея по порядку.  
2. Жми **УДАР** — буквы стены осыпаются (подсвечиваются заранее).  
3. Кнопка **!** подставляет подходящее слово из трея.  
4. После удара есть **эхо-окно** — бей вторым словом из осыпи.  
5. Не дай стене дойти до красной линии.

Словарь расширен (~2800 слов). В Норме стена растёт только по таймеру, не после каждого удара. Короткие слова тоже дают заметные очки.
