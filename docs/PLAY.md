# Как играть в «Эхо»

1. Тапай буквы трея → **УДАР** (подсказка «!» подставит слово).  
2. Осыпь даёт эхо-окно для второго удара.  
3. За забег получаешь **осколки** ◆ — ими покупаются стили.  
4. Меню → **✦ Стили**: кубики, фон, UI и частицы в 11 темах.

Стартовый стиль **Эхо Премиум** уже открыт. Новым игрокам — 250 осколков.
