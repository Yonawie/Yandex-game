# Как играть в «ЭХО»

```bash
npm install
npm run play
```

1. Выбери режим.  
2. Тапай буквы трея → собирай слово.  
3. **УДАР** — если слово есть в словаре и цепляет стену, кубики осыпаются.  
4. Пока горит **ЭХО-ОКНО** — бей вторым словом из упавших букв.  
5. Не дай столбам дотянуться до красной линии потолка.

**Ф / Ц / Щ** усиливают комбо и почти всегда запускают эхо-взрыв.
