1. `npm run pack` → `release/sotoslov-yandex.zip`
2. Консоль разработчика → создать игру HTML5 → загрузить zip
3. Ориентация: портрет
4. Категории: головоломки / слова
5. Иконка: `public/favicon.svg` (экспорт 512 PNG для витрины)
6. Проверить LoadingAPI / GameplayAPI / Rewarded на стенде

Модерация: словарь без политики/сквернословия; возраст 0+.
