# Живые картины

HTML5-игра для [Яндекс Игр](https://yandex.ru/games): поиск предметов на больших ярких «живых» картах с панорамированием и зумом.

## Особенности

- **6 карт**: зимний фестиваль, Париж, цирк, подводный город, джунгли, неоновый мегаполис
- **По 3 уровня на карту** (18 уровней)
- **По 15 предметов** на уровень (на карте размещено ~45 целей)
- Pan / zoom / pinch, подсказки через rewarded-рекламу
- Прогресс в `localStorage` + YaGames SDK

## Запуск локально

Нужен статикой-сервер (ES-модули):

```bash
npx --yes serve -l 4173 .
```

Открой http://localhost:4173

## Сборка для Яндекс Игр

Загрузите папку проекта как HTML5-игру. Точка входа — `index.html`. SDK подключается с `https://yandex.ru/games/sdk/v2`.

## Управление

- Перетаскивание — панорама
- Колесо / щипок / кнопки ± — масштаб
- Тап по предмету — найти
- 💡 — подсказка (реклама)
