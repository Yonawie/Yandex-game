# Эхо / Echo

Словесный экшен для **Яндекс Игр**: ломай стену букв своим словом.

- ТЗ: [`docs/TZ.md`](docs/TZ.md)
- Как играть: [`docs/PLAY.md`](docs/PLAY.md)

## Петля

1. Растёт стена из букв-кирпичей.  
2. Собери слово из трея → **УДАР** — совпавшие буквы осыпаются.  
3. Редкие Ф/Ц/Щ или плотный залп дают **ЭХО** (соседи тоже падают).  
4. На 3 секунды открывается **эхо-трей** из осыпи — успей второй удар.  
5. Стена доросла до потолка — конец.

## Запуск

```bash
npm install
npm run play
```
