# Плёнка / Filmword

Словесная стратегия размещения для **Яндекс Игр**.

Поле — мягкая **мыльная сетка** (не соты). Буквы из трея кладутся на соседние клетки; слово застывает кирпичом. Слова из 6+ открывают множители; ★ лопает поле пузырём. В **Бесконечности** сильная очистка сужает плёнку с краёв.

Стек: TypeScript + Vite + Canvas 2D + Yandex Games SDK.

- ТЗ: [`docs/TZ.md`](docs/TZ.md)
- Как играть: [`docs/PLAY.md`](docs/PLAY.md)

## Запуск

```bash
npm install
npm run play
```

## Почему «работают» слова

Трей **всегда** собирается вокруг случайного слова длины 3–5 из словаря (~1700 слов), плюс досыпка букв. Сброс тоже выдаёт играбельный набор.
